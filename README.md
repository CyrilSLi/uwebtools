# uwebtools

A collection of small web tools stored in a data URL.

## Usage

- Copy the data URL from `index.txt` and paste it in the browser address bar.
- Search tools on the top bar.
- Click the left textbox or hit `Tab` to start inputting your data.
- The results or any error will be displayed in the right textbox.

## Current tools

- Base64 encode/decode
- Caesar cipher of any shift
- Certain length text generator
- HTML data URL generator
- JSON beautify/minify
- Unicode inspector
- URL encode/decode
- Word count
